# Jenkins + Groovy Learning

Repositorio personal para documentar mi aprendizaje de Jenkins y Groovy desde cero, con miras a la migración de pipelines CI/CD en mi empresa.

## Estructura del proyecto

- `modulo-1-groovy/` - Fundamentos del lenguaje Groovy
- `modulo-2-jenkins/` - Conceptos core de Jenkins
- `modulo-3-pipelines/` - Anatomía del Jenkinsfile
- `modulo-4-groovy-avanzado/` - Groovy dentro de pipelines
- `modulo-5-patrones/` - Patrones profesionales (credenciales, parámetros, etc.)
- `proyecto-final/` - Pipeline integrador completo

## Tecnologías

- Jenkins (local en Windows)
- Groovy (Apache Groovy sobre JVM)
- Git + GitHub
